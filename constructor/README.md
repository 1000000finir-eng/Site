# Конструктор сайту (Tauri 2 + Svelte 5)

Локальний візуальний редактор сайту: сторінки й блоки, попередній перегляд «як на сайті», готові блоки з бібліотеки прикладів і вставки, жирний текст, публікація на GitHub одним кліком.
Працює з тими самими файлами, що й сайт (`src/_content/pages/*.json`, `src/_data/home.json`), і використовує **ті самі шаблони блоків**, що й збірка сайту (`../src/_includes`, каталог `../src/_includes/product/catalog.json`).

## Що потрібно для розробки (Windows)
- Node.js 20+, Rust (rustup), Microsoft C++ Build Tools, WebView2 (у Windows 10/11 є)
- У цій папці: `npm ci` (залежності сайту в корені репозиторію встановляться автоматично при першому запуску; або вручну `npm ci` у корені)

## Запуск і збірка
```
cd constructor
npm run tauri dev        # розробка
npm run tauri build      # інсталятор: src-tauri/target/release/bundle/nsis/*.exe
npm test                 # тест інтерфейсу (jsdom) ;  npm run test:logic — перевірка форм і блоків
```
Каталог блоків вбудовується у програму під час збірки. Додали або змінили блоки (`tools/catalog.py`, `./tools/build_catalog.sh` у корені) — перезберіть програму.

## Керування прямо на сторінці (перегляд)
- Наведіть на блок: зʼявляються кнопки **✎ редагувати, ＋ Вставка, ↑ ↓, ⧉ дублювати, 🗑 видалити**; між блоками — «＋ Додати блок тут».
- Наведіть на вставку (жовта рамка): ✎ / ↑ / ↓ / 🗑 для самої вставки.
- Головна: **карточки перетягуються між розділами** (і всередині розділу); у формі картки також є «Перенести в інший розділ».
- «Додати блок» і «Додати вставку» показують плитки з живим виглядом, пошук по назві.
- Кнопки 🖥 / 📱 над переглядом — ширина комп’ютера / телефону.

## Вільні блоки та елементи
- **Будь-який блок можна розібрати на елементи** (кнопка «Розібрати на елементи» внизу форми блоку): це дерево з абзаців, списків, фото, кнопок, контейнерів і **вставок**. Їх можна додавати, міняти місцями (↑ ↓), дублювати, видаляти. Усе, що не мало готової форми, теж розбирається — «сирого HTML» не лишається.
- «Особливі» блоки (section/raw) розбираються кнопкою у лівій панелі: «Розібрати тут» / «У всіх сторінках». Перевірено: зібраний сайт до і після розбору однаковий.
- Кнопка **＋ Вставка** над будь-яким блоком у перегляді працює завжди (за потреби спершу пропонує розібрати блок на елементи).
- Новий блок «Вільний блок» у каталозі додавання — порожній каркас з рамкою, куди кладете все, що потрібно.
- Видалення сторінки: кнопка «🗑 Видалити» у лівій панелі (разом із картками на головній, що ведуть на неї).
- `dragDropEnabled: false` у `tauri.conf.json` потрібне, щоб працювало перетягування карток у вікні (інакше Windows показує перекреслений кружок).

## Що потрібно власниці сайту
1. Встановити програму (інсталятор).
2. Встановити **Git for Windows** (git-scm.com, всі параметри за замовчуванням — разом із Git Credential Manager).
3. При першому запуску: «Завантажити сайт із GitHub» (адреса репозиторію) або «Обрати папку» з уже завантаженим сайтом.
4. Першу публікацію GitHub попросить увійти в акаунт у браузері — це робиться один раз.

## Примітка щодо збірки на Windows
Вотчер Vite не повинен стежити за `src-tauri` (інакше помилка EBUSY на `target`): у `vite.config.js` задано `server.watch.ignored: ["**/src-tauri/**"]`.

## Як влаштовано
- `src/lib/schema.js` — форми блоків з каталогу (та сама логіка, що й `tools/gen_config.py`)
- `src/lib/render.js` — попередній перегляд тими самими шаблонами, що й сайт; клік по блоку виділяє його
- `src/lib/store.svelte.js` — стан, автозбереження (локально), історія змін (Ctrl+Z / Ctrl+Y)
- `src/lib/git.js` — публікація: `git add` → `commit` → `pull --rebase` → `push`
- `src-tauri/src/lib.rs` — лише прості команди: файли та запуск `git`
